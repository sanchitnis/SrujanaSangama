Collect all fields marked **required**. Fields marked *optional* improve output quality.

## Section C — Curriculum Alignment (required)

| Field | Value |
|-------|-------|
| Course Outcomes addressed | (list CO numbers + full CO statements) |
| Bloom's Taxonomy level(s) | (Remember / Understand / Apply / Analyse / Evaluate / Create) |
| Programme Outcomes (POs) mapped | (optional — list PO numbers) |

**Example CO statement format:**
> CO3: Analyse the time and space complexity of sorting algorithms and justify algorithm selection for given constraints.

## Submission Checklist (for Claude to verify before proceeding)

- [ ] Course name, code, semester confirmed
- [ ] Session topic confirmed
- [ ] At least one CO with full statement provided
- [ ] Bloom's level confirmed
- [ ] Key concepts list (minimum 3 items) provided
- [ ] Session duration confirmed

If any required field is missing, ask the faculty specifically for that field before proceeding to material generation.
